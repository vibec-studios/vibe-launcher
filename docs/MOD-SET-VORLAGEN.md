# Mod-Sets als Vorlagen

Aktiviere im Editor eines Mod-Sets **Bei Neuanlage anwenden**. Vibe wählt das Set dann in neuen, selbst erstellten Java-Instanzen voraus. Du kannst mehrere Sets als Vorlage markieren und die Auswahl im Erstellen-Dialog für jede Instanz anpassen.

Die Prüfung zeigt, wie viele Inhalte zur gewählten Version und zum Loader passen. Vibe installiert passende Inhalte nach dem Erstellen. Beim Teilen oder Duplizieren eines Sets wird die Vorlageneinstellung nicht übertragen.
