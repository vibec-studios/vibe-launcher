# Datapacks pro Welt

Öffne in einer Java-Instanz den Tab **Welten** und wähle im Menü der Welt **Datapacks verwalten**. Du kannst ein vorhandenes Datapack aus der Instanz in diese Welt kopieren, eine Datapack-ZIP mit `pack.mcmeta` hinzufügen oder ein Pack aus der Welt entfernen.

Beende Minecraft vor Änderungen. Der Dialog verwaltet die Dateien im Datapack-Ordner der ausgewählten Welt. Einstellungen für einzelne Packs im Minecraft-Weltmenü werden im Spiel verwaltet.
