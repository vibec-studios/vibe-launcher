# ReplayMod installieren

Öffne **Instanz → Inhalte → Werkzeuge → ReplayMod**. Der Dialog zeigt die passende Release-Version aus dem offiziellen ReplayMod-Projekt auf Modrinth. **Installieren** lädt ReplayMod und seine Pflichtabhängigkeiten in die aktuelle Instanz. Eine deaktivierte Installation lässt sich dort wieder aktivieren. Beende vorher alle Sitzungen der Instanz.

Nach dem Start findest du deine Aufnahmen im **Replay Viewer** des Minecraft-Hauptmenüs. Für den optionalen Videoexport brauchst du FFmpeg. [ReplayMod-Dokumentation](https://www.replaymod.com/docs/)

Wie genau Vibey-Cosmetics in Aufnahmen wiedergegeben werden, muss mit einer echten Minecraft-Sitzung und dem Vibey Client geprüft werden.
